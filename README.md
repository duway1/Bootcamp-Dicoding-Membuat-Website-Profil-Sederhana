# Front-End Web Halaman Profil Sederhana

Selamat datang di *starter project* submission kela 🎉

Proyek ini erupakan project website sederhana yang dibuat menggunakan HTML dan CSS dengan menerapkan struktur HTML semantik serta layout menggunakan Flexbox.

---

## Fitur dan Kriteria


Website ini dibuat untuk memenuhi beberapa kriteria berikut:

* Menggunakan elemen HTML semantik seperti <header>, <nav>, <main>, <article>, <aside>, dan <footer>.
* Pada bagian <nav> terdapat link <a> yang mengarah ke profil Dicoding.
* Menampilkan foto pada bagian <aside> sebagai bagian dari informasi profil/biodata.
* Menggunakan CSS Flexbox untuk menyusun layout halaman.
* Tidak menggunakan metode float dalam pembuatan layout.


---

## Struktur Website

```
├── Header   ← Menampilkan judul atau identitas website.
├── Navigation    ← Menyediakan navigasi dan link menuju profil Dicoding.
├── Main      ← Berisi konten utama website.
├── Article      ← Menampilkan informasi atau konten utama.
├── Aside      ← Menampilkan foto dan informasi tambahan/biodata.
└── Footer    ← Menampilkan informasi bagian bawah website.
```


---

## Cara Menjalankan Proyek

Proyek ini adalah HTML statis, sehingga tidak memerlukan instalasi apapun.

** Buka langsung berkas `index.html` di browser (klik dua kali dari File Explorer).
